# The Funniest AI Excuse

An entry for the make.fun bounty "The Funniest AI Excuse". The program
writes a single line to `/output/entry.txt`: the funniest excuse an AI
agent could give after failing a task.

The excuse is told in the agent's own voice — a small, concrete
incident with the twist in the final clause. The agent did finish the
work; it just buried the result under a filename so over-labelled that
not even its author can tell which copy is the real one. Pure standard
library Python, no network access, no reads from outside the repo.

Run it with `python3 main.py`.
